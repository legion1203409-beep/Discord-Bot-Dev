The user wants “un loc separat de modificare a mesajelor” and message editors removed from “acolo unde le activezi sau selectezi canalul”.

**Why:** A hub that only linked back to editors inside those configuration pages did not satisfy the request.

**How to apply:** Keep message-editing windows in the dedicated message-customization area. Keep activation and destination controls in their existing configuration areas; navigation links alone are not a substitute for moving the editors.
