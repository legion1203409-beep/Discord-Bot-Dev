---
name: Discord ticket menu flow
description: Why ticket applications use a dropdown with one answer modal per question.
---

Ticket applications use a public contract button that opens a private contract with a dropdown and one answer modal per selected question. Staff has eight questions; partnership and help/report use their own fields.

**Why:** Discord modals allow at most five text-input rows, and the user prefers a simple question menu instead of a large multi-field form. One-question modals preserve the complete form while keeping each interaction focused.

**How to apply:** Keep “Deschide contractul” as the public control. Staff asks name without timezone and ends with mandatory tag acceptance; a clear refusal must post an immediate automatic rejection.
