---
name: Seasonal member messages
description: Calendar-driven holiday tone for AI welcome and departure messages.
---

AI welcome and leave messages keep the server's selected writing style while adding a light Halloween theme throughout October and a Christmas theme from December through January 6. Outside those periods, use only the configured style.

**Why:** the user requested Halloween- and Christmas-themed AI messages for both arrivals and departures.

**How to apply:** keep both event types in sync when changing the seasonal prompt, and retain the base style as an additional voice rather than replacing it.
